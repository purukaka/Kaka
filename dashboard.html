How this works

      

        This dashboard is a staging area, not a live publishing tool. Everything you type here saves automatically to this browser as you go — reopen the file later and it's still here.


        When you're ready to update the real site: open a tab, copy the generated HTML block from the bottom of each panel, then paste it into index.html between the matching <!-- START --> / <!-- END --> comment markers for that section. Save and re-upload index.html wherever purukaka.com is hosted.


        Note: because this saves to browser storage, it's local to whichever browser and device you're using it in — it won't sync across devices on its own.
